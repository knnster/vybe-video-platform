# VYBE — Video Sharing Platform

A responsive, dark-themed video-sharing frontend prototype.

## Features
- Responsive desktop and mobile layouts
- Video discovery feed, featured content, and creator stories
- Search and category filters
- Video preview modal
- Demo upload form
- Demo likes, saves, follow button, and comments
- GitHub Pages-ready static site

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Upload `index.html`, `README.md`, and `.nojekyll` to the root of your repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment URL to appear in the Pages settings.

## Important
This is a frontend prototype. The sample videos and creators are illustrative. Real accounts, permanent uploads, video streaming, and cross-device likes/comments require a backend, database, and video storage/streaming service. The upload form currently previews the flow but does not publish files to a server.
